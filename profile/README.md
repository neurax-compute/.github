**NEURAX Compute** turns idle computers, servers and devices into a computing network that companies can
actually trust. Customers buy computation through a simple API, partners provide the machines, and the
NEURAX coordinator makes sure every result is right before anyone is paid.

### What makes it different

- **Verified, not promised** — every result is checked before the customer is charged: recomputation of random
  blocks, mathematical checks, double execution on different partners. A wrong result is never paid.
- **Sovereign** — for every job the customer chooses *where* it runs (anywhere, Europe only, Switzerland only)
  and *by whom* (identity-verified partners only). The country of each node comes from its IP address, not from
  what the partner declares.
- **Provable** — every job comes with a digitally signed evidence file (ECDSA P-256) that an auditor can verify
  independently.
- **Instant** — with NEURAX Edge and our NEURAX Bounce algorithm, requests go to the node predicted to answer
  first and bounce to the next one if it is late.
- **In euro** — no tokens, no cryptocurrency. Double-entry accounting, card and bank transfer payments.

### What you can compute today

Option pricing (European, Asian, barrier) · portfolio Value-at-Risk and Expected Shortfall, including
historical simulation for Bitcoin and other volatile assets · matrix multiplication · your own Docker
containers · Blender 3D rendering · instant Edge functions.
